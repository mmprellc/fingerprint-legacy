# Print photos

These two photographs are real inked fingerprints, not drawings made for this project.

- `plain-whorl.jpg` — [Plain whorl in a right thumbprint](https://commons.wikimedia.org/wiki/File:Plain_whorl_in_a_right_thumbprint.jpg) by [Metrónomo](https://commons.wikimedia.org/wiki/User:Metr%C3%B3nomo), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0).
- `tented-arch.jpg` — [Tented arch in a left index fingerprint](https://commons.wikimedia.org/wiki/File:Tented_arch_in_a_left_index_fingerprint.jpg) by [Metrónomo](https://commons.wikimedia.org/wiki/User:Metr%C3%B3nomo), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0).

The regression runner adds a plain paper margin around each file before measuring it. The pixels of the prints themselves are the Wikimedia files, scaled down for the working size.
